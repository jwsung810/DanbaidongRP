# 출제 실패 패턴 카탈로그

실제 파이프라인 시험 5회분(미적분 30번 생성)에서 누적된 실패 모드. 제작자는 본 파일을 자체 검증 단계에서 반드시 점검할 것. 각 패턴은 **증상 → 원인 → 회피법**으로 정리.

---

## AP-1. π 무리수 부당 분리

**증상**
- 풀이가 다음 형태를 포함: "F(k) = (A/π) + B = 정수 k. π가 무리수이므로 A=0이고 B=k이다. 따라서 두 식 동시 성립."
- (실패 사례) 시도 1의 f(x)=3x³−2x, F(2)=0에서 (8a/3+4c)/π + (b+2d) = 0 분리.

**원인**
- 계수 a, b, c, d가 일반 실수일 수 있다는 점을 무시.
- 반례: a=1, b=4, c=−π−2/3, d=0도 동일 조건을 만족하지만 답이 달라진다.
- 또한 π의 초월성은 고등학교 교육과정 외 사실이라 학생 풀이로 사용 불가.

**회피법**
1. 적분구간이 sin(πx/2)의 **정수배 주기**(예: [0, 4], [0, 8])가 되도록 설계 → 홀수차 sin 항이 자동 0, 짝수차만 살음 → π 자동 소거.
2. 두 적분 값의 **차/합**을 조건으로 사용해 π 동반 항을 직접 약분 (예: F(2)+F(−2)의 짝성 활용).
3. F의 점값이 아니라 **F의 극값 위치, 부호, 또는 그래프 개형**을 조건으로 사용 → 적분 직접 계산 회피.
4. 발문에 "유리수 계수" / "정수 계수" 같은 분리 정당화 조건을 절대 추가하지 말 것 (평가원 격식 아님).

## AP-2. 출력 도중 자기 수정·무효 선언

**증상**
- 풀이 단계 도중 "이 조건을 (다')로 교체하자", "이 문제는 무효 처리" 같은 메타 코멘트가 본문에 섞임.
- 발문에서 묻는 값(예: f(5))과 풀이 결론(예: f(4))이 불일치.
- (실패 사례) 시도 2가 발문 f(5)→풀이 f(4)로 무단 변경, 시도 4가 "본 문항 무효" 선언.

**원인**
- 검증을 완료하지 않은 상태에서 최종 출력 본문 작성을 시작.
- 출력이 곧 사고 과정이 되어 결함을 발견하면 글 안에서 정정을 시도.

**회피법**
1. **2단계 출력 의무화** (creator.md에 명시):
   - Phase 0: 비공개 내부 검증 보고서 (출력 본문 전에 작성, 모든 자유도·반례·π 잔존·영역 정합성 점검 완료)
   - Phase 1: 최종 출력 본문 — Phase 0에서 통과된 설계만 옮겨 적기. **본문 도중 함수 형태·조건·묻는 값 변경 절대 금지**.
2. Phase 0에서 결함이 발견되면 그 자리에서 베이스라인(가장 단순한 작동 형태)으로 후퇴하여 다시 Phase 0 → Phase 1.
3. "본 문항 무효" / "재시도 필요" / "추후 호출에서 수정" 같은 출력 종료 문구 금지. 어떤 상황에서도 닫힌 형식의 한 문항을 제출.

## AP-3. 한 주기 적분으로 인한 자동 소거 (변별 붕괴)

**증상**
- F(4)=k 또는 ∫₀^{4n} h(t)dt=k 같은 조건이 sin·sin³ 항을 자동 0으로 만들어, **유효 식이 단 하나(b 결정용)** 로 축소.
- 풀이가 5~7분으로 끝나 16~19번 단답형 수준이 됨.
- (실패 사례) 시도 3의 f(x)=2x³+x², F(4)=2.

**원인**
- π 회피(AP-1)를 안전 패로 선택한 결과, 정보량이 너무 적은 조건이 됨.
- 변별 함정이 발문에 반영되지 않고 출제 의도로만 남음.

**회피법**
1. 한 주기 적분을 사용하되, **다른 조건들이 결합 추론을 요구**하도록 설계:
   - (나)를 합성함수 h의 극값 위치 + 값 동시 지정 (예: h가 x=1에서 극값 −2)
   - (가)에 함수방정식 형태 (f(x)+f(−x)=−2x² 같은) 으로 짝/홀 분리 통찰을 요구
2. **부분 주기 적분**을 사용하고 π는 두 식의 차/합으로 소거:
   - (다) ∫₀¹ h(t)dt + ∫₁² h(t)dt = (정수) 그리고 ∫₀¹ h(t)dt − ∫₁² h(t)dt = (정수). 후자는 cos항 살리고, 전자는 sin³항 살림 → 두 독립식.
3. 풀이 단계 수를 사전 카운트(자체 평가에 명시): 30번급은 **최소 4단계, 의미 있는 분기 1개 이상** 필요.

## AP-4. 영역 부정합 (미적분 위장 문제)

**증상**
- 발문이 "미적분 30번"이라 표방하지만 풀이에 합성함수 미분, 초월함수, 매개변수, 음·역함수, 무한급수, 정적분의 도형 활용 등 **미적분 고유 개념이 전혀 등장하지 않음**.
- 다항함수만 사용 → 사실상 수학Ⅱ 미적분 영역.
- (실패 사례) 시도 5의 f(x)=x³−2x²−3x, f(x)+f(−x)=−4x², ∫₁² 다항 적분. 미적분 고유 개념 0개.

**원인**
- π·삼각함수 등을 회피하려다 다항으로 후퇴.
- "수학적 무결성"과 "영역 정합성"이 충돌할 때 후자를 포기.

**회피법**
1. 리더 브리프의 "미적분 고유 개념 사용 위치"를 제작자가 반드시 준수.
2. 미적분 30번이라면 풀이의 **본질 단계 하나 이상**이 다음 중 하나여야 함:
   - 합성함수 미분 d/dx f(g(x)) = f'(g(x))·g'(x) — 단, g가 비다항(sin, e^x, ln x 등).
   - 매개변수 미분 dy/dx = (dy/dt)/(dx/dt) — t는 명시적 매개변수.
   - 역함수 미분 (f⁻¹)'(b) = 1/f'(a).
   - 정적분으로 정의된 함수 F(x)=∫_a^x f(t)dt의 극값/그래프 분석 — f가 비다항.
   - 무한등비급수 + 도형 닮음.
   - 회전체 부피, 곡선의 길이.
3. 다항함수만 사용했다면 자체 평가에서 "미적분 30번이 아님 (수학Ⅱ급)"이라고 명시하고, 영역에 맞는 함수로 재설계.

## AP-5. 누적 학습 부재 (같은 함정 반복)

**증상**
- 시도 N에서 검토자가 지적한 결함을 시도 N+2에서 다시 범함.
- 매 루프가 직전 피드백만 보고 작업하므로 N-2회 전의 학습이 휘발됨.

**원인**
- SKILL.md가 `last_feedback`(직전 검토만)을 전달하고, 누적 노트를 유지하지 않음.

**회피법**
- SKILL.md가 `learning_notes`를 누적 유지. 각 루프 검토자의 "핵심 결함"과 "구체 수정안"을 모두 모아 다음 제작자에 전달.
- 제작자는 매 호출에서 누적 노트의 **모든 항목을 자체 검증 보고서에서 점검**.

## AP-6. 독창성 휘발 (같은 골격 미세 변주)

**증상**
- 5회 루프 동안 같은 함수 골격(예: "정사각형 + 사분원 + 직각이등변" 또는 "삼차함수 + ∫·F(k) 조건")만 반복하고 변경은 계수·번호·라벨 수준에 머묾.
- 검토자가 매번 "발상의 독창성 0.5~0.9/1.5", "기시감 강함", "평가원 기출 ○○○○년 ○○번 변형 범위" 평가.
- 점수가 6~8점대에서 천장 형성. 핵심 결함 항목에 "독창성 회귀" 반복 등장.
- (실패 사례) 미적 29번 5회 루프: 1차 정사각형 변 2 / 3차 변 3 / 4차 변 3+r비율 표기만 변형, 골격 동일 → 독창성 만점 불가.

**원인**
- 리더가 첫 브리프에서 단일 골격을 고정 → 5회 동안 베이스라인 폴백이 같은 골격으로 회귀시킴.
- 검토자 채점 기준상 "독창성"은 평가원 기출 데이터베이스 비교가 자동 감점 트리거. 골격을 바꾸지 않으면 만점 불가능.
- "변별 함정 강화"와 "독창성"이 trade-off가 됨 — 골격 강화는 함정을 약화하고, 함정 강화는 골격 변형 여지를 좁힘.

**회피법**
1. **리더가 후보 골격 2개 이상 제시**: 첫 브리프에 "주 골격 + 대체 골격"을 함께 명시. 3회차에서 점수가 정체되면 대체 골격으로 강제 전환.
2. **베이스라인 폴백의 적용 범위 제한**: 점수 후퇴 시에도 "함수 형태"가 아닌 "구조적 제약(답 형식·k 범위)"만 회귀. 함수 자체는 매 루프 변형 가능하게 둠.
3. **SKILL이 점수 정체 감지 시 리더 재호출(replan)**: `iteration ≥ 3` AND `max_score - min_score < 1.0` AND `best_score < 8.0` 이면, 리더에게 "현재 골격 폐기, 다른 단원/패턴으로 브리프 재작성" 지시 후 루프 재시작 (1회 한정).
4. **제작자 Phase 0에 "독창성 자가진단" 항목 추가**: "본 시도의 함수 골격이 평가원 어떤 기출과 가장 유사한가? 차별점은 어디인가?" 명시. 차별점이 단순 계수 변경이면 골격 자체를 변경.

## AP-7. 함정 자동 해소 (변별 무력화)

**증상**
- 브리프에 약속된 변별 함정(작도 분기, 영역 부호, k vs k² 등)이 발문 본문에서 너무 친절하게 명시되어 학생이 함정을 의식조차 하지 않게 됨.
- 검토자가 "변별 포인트 0.2~0.3/0.5", "함정이 작동 안 함", "발문이 분기를 직접 봉쇄" 평가.
- 한 함정을 살리려고 다른 함정이 자동 해소되는 trade-off 발생.
- (실패 사례) 미적 29번 5차: "(다)에서 두 접선과 두 변으로 둘러싸인 영역" 명시로 작도 분기 봉쇄, "Q_n과 T_n 분리" 자명하여 영역 부호 함정 무력, 단일 함정만 남음.

**원인**
- 제작자가 "발문 모호성을 줄이려"는 안전 본능에 따라 분기 후보를 모두 제거.
- 검토자가 "수능 유사도(평가원 격식)"와 "변별 포인트 명확성"을 동시에 채점하므로, 격식을 위해 모호성을 줄이면 함정도 사라짐.

**회피법**
1. **함정은 발문이 안내하지 말고 학생이 발견하도록**: 함정 후보(예: 잘못된 작도)를 발문에서 차단하지 말고, "정답 작도가 유일하다"는 결론을 학생이 직접 도출하게 한다. 단 그 결론 도출이 발상 1단계로 압축되면 안 됨.
2. **함정 ≥ 2개를 동시 활성화**: 30번급은 변별 함정 2개 이상이 동시 작동해야 만점. 한 함정만으로는 0.3/0.5 천장.
3. **Phase 0에 "함정 작동 시뮬레이션"**: 제작자는 평균적 학생이 어떤 잘못된 경로로 빠질 수 있는지 1개 이상 명시. 그 경로가 발문 한 줄로 차단된다면 함정이 아닌 가이드.
4. **검토자 권고**: "구체 수정안"에서 "함정 추가" 권고 시, 그 함정이 답 형식이나 다른 함정을 깨지 않는지 사전 점검을 요구. 위험이 있으면 단원 자체 변경을 권고.

## AP-8. 단원/골격 단일 고착 (리더 1회 호출의 그늘)

**증상**
- 리더가 첫 브리프로 한 가지 골격을 정하면, 5회 루프 동안 그 골격의 천장(보통 7~8점)을 못 넘음.
- 단원이 미적분이지만 "무한등비급수 + 도형 닮음" 한 패턴만 반복하여 다른 미적분 패턴(매개변수, 정적분의 도형 활용, 합성함수 극값)을 시도조차 하지 않음.
- 5회 모든 시도가 동일 패턴 → 누적 학습 노트가 같은 결함을 다른 표현으로 반복 지적.

**원인**
- SKILL.md가 "리더는 1회만 호출"로 명시 → 점수 정체 시에도 골격 재정의가 불가능한 구조.
- 리더 자신도 첫 호출에서 가장 안전한 골격(평가원 빈출)을 선택하므로 독창성 천장 자동 형성.

**회피법**
1. **리더 첫 브리프에 "대체 골격 1~2개" 의무 명시**: 주 골격이 점수 정체에 빠지면 즉시 전환할 수 있도록 사전 준비. SKILL이 대체 골격을 학습 노트에 함께 전달.
2. **SKILL의 replan 트리거**: `iteration ≥ 3` AND `best_score < 8.0` AND `score 변동 < 1.0` 이면, 리더 재호출 (전체 5회 중 1회 한정). 재호출 시 "이전 골격 폐기, 누적 학습 노트 + 시도된 골격 목록 전달, 새 골격으로 새 브리프 작성" 지시. 재호출 후 남은 루프(보통 2회)에서 새 골격으로 시도.
3. **제작자가 "골격 변경" 권한 가짐**: 누적 노트의 모든 시도가 동일 핵심 결함이라면, 제작자는 베이스라인을 무시하고 다른 골격으로 도전 가능. 단 이는 Phase 0 보고서에 명시적 사유 기재 필수.
4. **사용자에게 단원 재정의 권고 강화**: 스킬 종료 시 "현재 단원/골격에서는 X점이 천장입니다. Y 단원으로 다시 호출하면 더 높은 점수가 가능합니다" 같은 구체 권고를 SKILL이 자동 출력.
