# 대표 문제 사례 (단원별, 출처·풀이 발상 포함)

각 사례는 출처 명시. 문제 원문 전체 인용은 저작권상 생략하고 **출제 의도·핵심 발상·함정**을 압축적으로 정리.

## A. 수학Ⅰ

### A-1. 지수·로그함수: 그래프 교점 + 정수 조건

**사례: 2026학년도 수능 공통 22번 (단답형 4점)**
- 출처: 2026수능 정답표(평가원), 나무위키 「2026학년도 대학수학능력시험/의견」.
- 단원: 지수함수.
- 발문 요지: 지수함수의 그래프 위의 두 점 A, B와 점과 직선 사이의 거리 조건이 주어졌을 때 조건을 만족하는 값을 구하는 문제. 점 A를 y=x에 대칭시켜 역함수(로그함수) 그래프와의 관계로 해석.
- 풀이 발상:
  1. y=x 대칭 → 역함수 그래프(로그함수) 도입.
  2. 일직선상 + 거리 조건 → 비례 관계(예: 두 배).
  3. 미정계수 a, b를 점의 좌표 식으로 정리.
- 함정: 지수함수와 그 역함수가 y=x에 대해 대칭이라는 점을 그래프 그리지 않고 식으로만 다루면 시간이 늘어남.

### A-2. 삼각함수: 코사인법칙 + 사인법칙 융합

**사례: 2026학년도 수능 공통 14번 (객관식 4점)**
- 출처: 오르비 「26수능 수학 손풀이」, 나무위키.
- 단원: 삼각함수의 활용 (사인법칙·코사인법칙).
- 발문 요지: 삼각형에서 한 각 또는 한 변의 정보로부터 다른 변·각을 구하는 도형 문제.
- 풀이 발상:
  1. 한 각의 cos, sin 값을 양쪽 다 적어둔다(서로 다른 법칙에서 필요).
  2. 코사인법칙 c² = a² + b² - 2ab·cos C 로 변의 길이.
  3. 사인법칙 a/sin A = 2R 로 외접원 반지름 또는 다른 각.
- 함정: 둔각·예각 분기를 빠뜨리거나 cos이 음수인 경우를 누락.

### A-3. 수열: 절댓값 점화식 케이스 분기

**사례: 2025학년도 수능 공통 22번 (단답형 4점)**
- 출처: 수학올인 블로그 (suhakallin.com/256), 나무위키 「2025학년도 대학수학능력시험/의견」.
- 단원: 수열 (점화식).
- 발문 요지: 수열 {a_n}이 절댓값을 포함한 점화식과 조건 (가)(나)를 만족시킬 때 가능한 첫째항들의 합을 구하시오.
- 풀이 발상:
  1. 조건 (나)에서 |a_1| ≠ |a_3|, |a_2| ≠ |a_3|, |a_3| = |a_5| 세 식 추출.
  2. a_3가 홀수인 경우 |a_3| = |a_3 - 1|/2 ⇒ a_3 = -3 또는 1.
  3. 각 경우에서 a_1을 거꾸로 추적 + 조건 검증.
- 함정: 절댓값에서 부호 분기를 단순화하다 케이스 누락. 평소 22번이 다항함수였기 때문에 수열 출제로 당황한 수험생 많음.

### A-4. 수열: Σ + 그래프 위 격자점

**사례: 2022학년도 수능 공통 (수학Ⅰ 영역, 14번 합답형)**
- 출처: 봉봉수학 「2022 수능 수학 14번」, 나무위키.
- 단원: 수열의 합·등차수열.
- 발문 요지: 수직선 위에서 움직이는 점의 위치와 속도에 관한 ㄱㄴㄷ 합답형.
- 풀이 발상:
  1. 위치-속도-가속도 관계 (속도 = 위치의 도함수).
  2. ㄱ: 단순 대입으로 확인.
  3. ㄴ·ㄷ: 평균값 정리/사잇값 정리로 해의 존재성 판단.
- 함정: 사잇값 정리의 조건(연속) 확인을 건너뛰면 ㄷ을 못 풂.

## B. 수학Ⅱ

### B-1. 함수의 극한과 연속: 좌·우극한 + 미정계수

**전형 유형 (회차 다수에 반복 등장, 8~12번)**
- 단원: 함수의 극한·연속.
- 발문 형식: "함수 f(x) = { (x ≤ a 일 때) g(x), (x > a 일 때) h(x) } 가 실수 전체에서 연속일 때, 상수 a, b의 값을 구하시오."
- 풀이 발상:
  1. 좌극한 lim_{x→a-} g(x) = 우극한 lim_{x→a+} h(x) = f(a).
  2. 연립방정식 정리.
- 함정: 점 a에서 함숫값 f(a)가 g(a)와 h(a) 중 어느 정의를 따르는지 확인.

### B-2. 다항함수의 미분: 삼차함수 결정 (22번 단골)

**사례: 2024학년도 수능 공통 22번 (단답형 4점, 정답 483)**
- 출처: 헤럴드경제, 수학올인 (suhakallin.com/105), 봉봉수학.
- 단원: 수학Ⅱ 미분, 다항함수 그래프 추론.
- 발문 요지: "최고차항의 계수가 1인 삼차함수 f(x)와 실수 전체에서 미분가능한 함수 g(x)가 다음 조건을 만족시킨다. (가) ... (나) ... f(4)의 값을 구하시오." (정답률 1.4~1.5%, EBSi 오답률 98.6%)
- 풀이 발상:
  1. 미분계수의 부호로부터 삼차함수가 두 번 꺾이는 개형 추론.
  2. x = 0의 위치가 감소구간임을 파악.
  3. 박스 안 조건 해석 → f의 극값·접선·근의 조건으로 미정계수 결정.
- 함정: "조건이 (가) 하나"로 보이는 간결한 발문이지만 그 안에 케이스 분기가 다수 함축됨. 절댓값 미분계수 함수 |f'(x)|를 잘못 다루면 풀이 폭주.

### B-3. 적분: 정적분으로 정의된 함수의 극값

**사례: 2024학년도 수능 미적분 30번 (단답형 4점, EBSi 오답률 96.3%)**
- 출처: 베리타스알파 「2024수능 미적 30번」, suhakallin.com/104.
- 단원: 정적분으로 정의된 함수 + 삼각함수 + 변곡접선.
- 발문 요지: 정적분으로 정의된 함수 F(x) = ∫_a^x f(t)dt 가 극대/극소가 되는 점의 성질을 이용해 함수식 결정.
- 풀이 발상:
  1. F'(x) = f(x). F가 극값 ⇔ f(x) = 0이면서 부호변화.
  2. 변곡접선 개념 (이차도함수가 0이고 변곡점에서의 접선) 활용.
  3. 구간별 정의된 함수의 그래프를 정밀하게 그려 케이스 추적.
- 함정: 변곡접선의 정확한 정의를 모르면 함수 개형을 잘못 잡음. EBS 연계 개념이지만 응용 수준이 매우 높음.

### B-4. 적분: 속도-위치-이동거리

**사례: 2022학년도 수능 공통 14번 (객관식 4점, EBSi 오답률 70.4%)**
- 출처: 봉봉수학 「2022 수능 수학 14번」, 나무위키 2022 의견.
- 단원: 수학Ⅱ 정적분의 활용.
- 발문 요지: 수직선 위를 움직이는 두 점 P, Q의 속도 v_P(t), v_Q(t)가 주어졌을 때 만나는 시각 또는 이동거리의 차를 구하는 합답형(ㄱㄴㄷ).
- 풀이 발상:
  1. 위치 x(t) = ∫_0^t v(s)ds + x(0).
  2. 이동거리 = ∫|v(t)|dt (속도의 절댓값 적분, 위치 변화량과 다름).
  3. 두 점이 만나는 시각 = x_P(t) = x_Q(t).
- 함정: "이동거리"와 "위치 변화"의 차이. 절댓값 빠뜨리면 오답.

## C. 미적분 (선택)

### C-1. 수열의 극한: 무한등비급수 + 도형 닮음 (29번 단골)

**전형 유형 (2014~2024 미적/가형 단답형 19~29번 반복)**
- 출처: 오르비 「미적분 29번 예측」, 봉봉수학 미적 29번 시리즈, 수학올인 (suhakallin.com) 연도별 풀이, 평가원 기출 PDF.
- 단원: 무한등비급수의 도형에의 활용.
- 발문 요지: 도형 R_1을 정의 → 시행으로 R_2, R_3 ... → R_n에 색칠된 부분의 넓이 S_n → lim_{n→∞} S_n 의 값을 구하시오.

#### 정형 발문 양식 (필수 모방)

```
그림과 같이 [초기 도형 A_1B_1C_1...의 변 길이·각도 명시]이 있다.
[보조 도형: 반원·부채꼴·내접원·접선 등 자연어로 그린다.]
[색칠 규칙: 어떤 영역을 색칠하는지 자연어로 명시.]
색칠하여 얻은 그림을 R_1이라 하자.

그림 R_1에 다음과 같은 시행을 하여 그림 R_2를 얻는다.
[다음 단계 닮은 도형 A_2B_2C_2의 작도 — 수선의 발/중점/접점 등으로 결정.]
[A_2 = ?, B_2 = ?, C_2 = ? 라벨링 명시. ∠B_2 = π/2 같은 직각 위치 보존도 명시.]
그림 R_1을 얻은 것과 같은 방법으로 [새 도형]에 같은 보조 도형을 그리고
같은 규칙으로 색칠한 영역을 그림 R_1에 추가하여 그림 R_2를 얻는다.

이와 같은 시행을 계속하여 n번째 얻은 그림을 R_n이라 하고, 
그림 R_n에 색칠되어 있는 부분의 넓이를 S_n이라 하자.

lim_{n→∞} S_n 의 값을 구하시오.
또는 (분수화 시):
lim_{n→∞} S_n = (pπ + q√3)/r 일 때, p+q+r의 값을 구하시오.
(단, p, q, r은 자연수이고 gcd(p, q, r) = 1이다.)
```

#### 풀이 발상
1. S_1의 넓이 계산 (직각삼각형/부채꼴/활꼴 등의 차분 넓이).
2. 닮음비 k → 넓이비 k².
3. 무한등비급수 합 = S_1 / (1 − k²). (R_n이 누적이므로 lim_{n→∞} S_n이 그 합.)

#### 변별 함정
- 닮음비를 변의 비가 아니라 넓이의 비로 착각 → 공비를 r로 잡아 답이 어긋남.
- S_1을 단일 도형(부채꼴만/삼각형만)으로 잡아 차분 넓이 한 항이 누락.
- 도형 작도에서 직각·접점 조건을 빠뜨림.
- "B_n과 같은 쪽 / 반대쪽" 표기 모호로 반원 방향 오인 → 정형은 "삼각형 A_nB_nC_n을 포함하는 쪽의 반원".

#### 정답률·난이도
- 평가원 미적 29번 평균 정답률: 20~40%. 회차에 따라 변동.
- 풀이 시간: 8~13분.

#### 양식 위반 빈출 사례 (제작자가 자주 범하는 실수)

| 비격식 | 정형 |
|---|---|
| "다음 그림과 같이" / "아래 그림과 같이" | **"그림과 같이"** |
| "그림 R_n에서 다음 절차를 수행한다" | **"그림 R_n에 다음과 같은 시행을 하여 그림 R_{n+1}을 얻는다"** |
| "S_n = ω_n − △ + Q_n" 수식 직접 정의 | **자연어로 색칠 영역 묘사 + "색칠되어 있는 부분의 넓이를 S_n이라 하자"** |
| 좌표 명시 (예: B_1 = (0,0), A_1 = (0,2)) | **좌표 사용 X. "∠B_1 = π/2, A_1B_1 = 2, B_1C_1 = 1" 같은 변/각만** |
| "(단계 1) ... (단계 2) ..." 라벨 | **자연어 문단으로 흐름 서술** |
| "Σ_{n=1}^{∞} S_n의 값" | **"lim_{n→∞} S_n의 값"** (R_n이 누적 그림이므로) |
| "B_1과 같은 쪽 / 반대쪽 반원" | **"삼각형 A_1B_1C_1을 포함하는 / 포함하지 않는 쪽의 반원"** |

#### 실제 평가원/수능 회차별 발문 양식 데이터

조사 회차: 2014~2024학년도 미적/가형 18~29번 (출처: 수학올인 suhakallin.com, 봉봉수학 bonbonmath.com, 오르비 orbi.kr 손풀이).

공통 정형 표현(거의 100% 일치):
- 도입: **"그림과 같이"**
- 시행 표현: **"다음과 같은 시행을 하여 그림 R_{n+1}을 얻는다"**
- 색칠 명명: **"색칠되어 있는 부분의 넓이를 S_n이라 하자"**
- 종결(단답): **"lim_{n→∞} S_n의 값을 구하시오."**
- 종결(객관): **"lim_{n→∞} S_n의 값은?"**

회차별 차이:
- 2014~2018: 도형 비교적 단순(정사각형·정삼각형 분할). 자연수화 조건 명시 빈도 낮음.
- 2019~2022: "시행" 표현이 정착. 도형 차분 넓이 + 닮음비 무리수화(√3, √5 등) 증가.
- 2023~2024: 단답형 자연수화 시 "p, q, r은 자연수, gcd(p,q,r)=1" 또는 "p, q, r은 서로소인 자연수" 명시 빈도 증가.
- 2026: 도형 대신 공비 추론형이 30번에 등장하기도 함 (이례적).

권장 모방 베이스: **2019~2022 양식**.

### C-2. 여러 가지 함수의 미분: 합성함수 + 삼각함수

**사례: 2025학년도 수능 미적분 30번 (단답형 4점)**
- 출처: 베리타스알파, suhakallin.com/255.
- 단원: 합성함수의 미분 + 삼각함수.
- 발문 요지: 함수 f(x) = sin(ax + b) 형태로 정의된 함수가 주어진 극값 조건을 만족할 때 n의 값을 구하시오. f(0)=0, f(2π) 조건에서 sin(2πa+b) = 2πa+b이므로 2πa+b=0 (sin x = x 의 해는 x=0).
- 풀이 발상:
  1. f(0) = 0 ⇒ sin(b) = 0 ⇒ b = mπ.
  2. f(2π) 자체 = 2πa+b 라는 조건 + sin(x)=x 의 유일해 x=0.
  3. 도함수 f'(x) = a·cos(ax+b)의 주기성으로 극값 개수 카운트.
- 함정: "sin x = x ⇒ x = 0"이라는 한정. 주기성에서 극값을 셀 때 구간 양 끝의 경계 처리.

### C-3. 여러 가지 적분: 치환 + 부분적분 결합

**사례: 2025학년도 수능 미적분 28번 (객관식 4점)**
- 출처: 베리타스알파, 수학올인 블로그.
- 단원: 치환적분·부분적분.
- 발문 요지: 정적분의 값을 구하는 "적분 퍼즐" 형 객관식.
- 풀이 발상:
  1. 적분 구간을 보고 치환할 변수 t 후보 선정.
  2. dx → dt 변환, 적분 구간 변환.
  3. 부분적분 ∫u dv = uv - ∫v du 한 번 더 적용.
- 함정: 치환 후 적분 구간을 그대로 두는 실수. 부분적분의 u, dv 선택 오류로 적분이 더 복잡해지는 경우.

### C-4. 미적분 최고난도: 역함수 미분 + 그래프 교점

**사례: 2026학년도 수능 미적분 30번 (단답형 4점, 정답 11)**
- 출처: 베리타스알파 「2026수능 미적 30번」, 나무위키 2026 의견.
- 단원: 역함수의 미분법 + 합성함수 + 그래프 추론.
- 발문 요지: 증가하는 연속함수 f의 역함수 g와 어떤 정점을 지나는 직선의 기울기 m에 따라 곡선과 직선의 교점 개수를 구하시오.
- 풀이 발상:
  1. 모든 조건을 역함수 g에 대해 재서술. 정점 (1,0) → (0,1), 기울기 m → 1/m.
  2. (0,1)에서 지수함수에 접하는 기울기를 원점 대칭+평행이동으로 (-1,-3)에서 e^x - 1에 그은 접선으로 환산.
  3. 교점 개수 함수의 불연속점 카운트.
- 함정: f를 직접 구하거나 그리려 시도하면 시간 폭주. **역함수 g로 시야를 통째 옮기는 발상**이 핵심. 사교육 스킬을 무력화하기 위해 의도적으로 설계된 문항.

### C-5. 미적분 30번: 치환적분 + 역함수 그래프

**사례: 2022학년도 수능 미적분 30번 (단답형 4점, 정답 143, EBSi 오답률 93.9%)**
- 출처: 봉봉수학 「2022 수능 수학 미적분 30번」, 베리타스알파.
- 단원: 적분, 역함수 그래프.
- 발문 요지: 주어진 조건을 만족하는 함수 f에 대한 정적분 값을 구하시오.
- 풀이 발상:
  1. 부분적분으로 적분 식을 정리.
  2. 치환적분으로 역함수와의 관계를 활용.
  3. ∫_a^b f(x)dx + ∫_{f(a)}^{f(b)} f^{-1}(y)dy = b·f(b) - a·f(a) 공식 활용 가능.
- 함정: 역함수의 적분 공식을 도출하지 못하면 적분 자체가 안 풀림. 그래프를 그려 직사각형 넓이로 환산하는 발상이 자주 사용됨.
