# 자주 등장하는 발문/조건 패턴, 합답형 양식

수능 스타일 문제 생성 시 모방해야 할 한국어 발문·표기·조건 진술 양식 정리.

## 1. 표준 발문 종결어

수능 수학 문제의 종결어는 정해진 몇 가지로 한정된다.

| 형태 | 사용 위치 | 예시 |
|---|---|---|
| "~의 값은?" | 객관식 (1~15, 23~28) | "f(2)의 값은?" |
| "~을(를) 구하시오." | 단답형 (16~22, 29~30) | "f(3)의 값을 구하시오." |
| "~의 개수를 구하시오." | 경우의 수형 단답 | "조건을 만족시키는 함수 f(x)의 개수를 구하시오." |
| "~의 최댓값은?" / "~의 최솟값은?" | 객관식 | "ab의 최댓값은?" |
| "~의 합을 구하시오." | 단답형 | "모든 a의 값의 합을 구하시오." |

주의: 객관식과 단답형의 종결어를 절대 섞지 않는다.
- 객관식: "~은?" / "~인가?" (의문형, 답 1~5 선택)
- 단답형: "~을 구하시오." (명령형, 0~999 정수)

## 2. 조건 나열 양식 (가)(나)(다)

표준 형식:

```
함수 f(x)가 다음 조건을 만족시킨다.

(가) 모든 실수 x에 대하여 f(x) = f(-x)이다.
(나) f(1) = 0이고 f'(1) = 2이다.
(다) lim_{x→∞} f(x)/x^2 = 1

f(3)의 값을 구하시오.
```

### 양식 규칙

- "함수 f(x)가 **다음 조건을 만족시킨다.**" (현재형, "만족한다"가 아니라 "만족시킨다") — 수능 표준 표현.
- 조건 라벨: (가), (나), (다), (라) 순서. 알파벳이나 ①②③ 사용 안 함.
- 각 조건은 마침표로 종결.
- 조건 본문 안에서 "이다", "이고", "이다." 의 격식체 사용.
- 마지막에 빈 줄 후 본 문제 발문.

### 조건의 전형적 내용 카테고리

1. **함숫값/미분계수 지정**: "f(1) = 3이다.", "f'(0) = 2이다."
2. **함수의 형태 지정**: "최고차항의 계수가 1인 삼차함수이다.", "이차함수이다."
3. **모든 실수에 대한 한정**: "모든 실수 x에 대하여 ...이 성립한다."
4. **극한/연속 조건**: "함수 f(x)는 실수 전체의 집합에서 연속이다.", "lim_{x→a} f(x) = b 이다."
5. **부등식/방정식 조건**: "방정식 f(x) = k의 서로 다른 실근의 개수가 3이다."
6. **극값/접선 조건**: "함수 f(x)는 x = 2에서 극값 5를 갖는다."
7. **그래프/도형 조건**: "곡선 y = f(x) 위의 점 (1, 2)에서의 접선의 기울기는 3이다."

## 3. 자주 쓰이는 한정·도입 표현

| 표현 | 의미·용법 |
|---|---|
| "모든 실수 x에 대하여" | for all x ∈ R |
| "양의 실수 x에 대하여" | for x > 0 |
| "임의의 자연수 n에 대하여" | for all n ∈ N |
| "두 실수 a, b에 대하여" | 두 변수 도입 |
| "0이 아닌 실수 x에 대하여" | x ≠ 0 조건 |
| "실수 전체의 집합에서" | 정의역 명시 |
| "함수 f(x)는 ~에서 연속이다" | 연속성 |
| "함수 f(x)는 ~에서 미분가능하다" | 미분가능성 |
| "f(x)가 x = a에서 극값을 갖는다" | 극대/극소 |
| "두 곡선 y = f(x)와 y = g(x)가 만난다" | 교점 존재 |
| "방정식 f(x) = 0의 서로 다른 실근의 개수" | 실근 카운트 |
| "함수 f의 역함수를 g라 하자" | 역함수 도입 |

## 4. 빈칸 추론형 ("다음은 ~을 구하는 과정이다")

전형적 발문:

```
다음은 함수 f(x)가 조건 (가), (나)를 만족시킬 때, f(3)의 값을 구하는 과정이다.

(풀이 시작)
조건 (가)에서 [...]이므로
f(x) = (가) 으로 놓을 수 있다.
이때 조건 (나)에 의하여
[...]
따라서 f(3) = (다) 이다.

위의 (가), (나), (다)에 알맞은 값을 각각 p, q, r라 할 때, p+q+r의 값은?
```

### 양식 규칙

- 발문은 "다음은 ~을 구하는 과정이다."로 시작.
- 빈칸은 (가), (나), (다)로 표시. 본 조건의 (가)(나)(다)와 라벨이 중복돼도 그대로 사용.
- 마지막에 빈칸 값의 합/곱/특정 함수값을 묻는 형태로 마무리.
- 2015 개정 교육과정 이후 출제 빈도 감소했으나 평가원 모의평가에서는 여전히 등장.

## 5. 합답형(ㄱㄴㄷ) 양식

전형적 발문:

```
함수 f(x) = ... 에 대하여 [보기]에서 옳은 것만을 있는 대로 고른 것은?

[보기]
ㄱ. f(1) = 0이다.
ㄴ. 함수 f(x)는 x = 2에서 극값을 갖는다.
ㄷ. 방정식 f(x) = k가 서로 다른 세 실근을 갖도록 하는 실수 k의 개수는 2이다.

① ㄱ    ② ㄴ    ③ ㄱ, ㄴ    ④ ㄱ, ㄷ    ⑤ ㄱ, ㄴ, ㄷ
```

### 합답형 양식 규칙

- 발문: "[보기]에서 **옳은 것만을 있는 대로 고른 것은?**" (정형 문구)
- 보기 라벨: ㄱ, ㄴ, ㄷ (3개). 4개(ㄱ,ㄴ,ㄷ,ㄹ)는 거의 없음.
- 선지 5개의 분포 관행:
  - ㄱ만 포함하는 선지가 1개
  - ㄴ만 또는 ㄷ만 단독 선지는 드묾
  - ㄱ+ㄴ, ㄱ+ㄷ, ㄱ+ㄴ+ㄷ 등 ㄱ을 포함한 조합이 다수
- **평가원 내부 규칙**(통설): ㄷ을 풀어야만 답이 결정. ㄷ을 풀지 않고 답이 나오는 풀이는 함정. (출처: 오르비 「평가원 수학 찍기 공략 #1 ㄱㄴㄷ」)
- 난이도: ㄱ < ㄴ < ㄷ. ㄱ은 거의 모두 맞도록, ㄷ은 변별을 위해.

## 6. 그래프/표 제시형

### 6.1 그래프 제시

```
함수 y = f(x)의 그래프가 그림과 같을 때, [...]
(그림: 좌표평면 위 곡선 + 특정 점 표시)
```

- 그래프에는 좌표축, 함수 그래프, 특정 점의 좌표 또는 (a, f(a)) 표기.
- "그림과 같이"로 자주 시작.
- 좌표값은 작은 정수(예: -2, -1, 0, 1, 2, 3) 중심으로 그려짐.

### 6.2 표 제시 (드묾, 주로 수열)

```
수열 {a_n}의 처음 다섯 항은 다음 표와 같다.
| n   | 1 | 2 | 3 | 4 | 5 |
| a_n | 2 | 5 | 8 | 11| 14|
```

## 7. 수식 표기 관행

### 7.1 함수·미분

- 함수: f(x), g(x), h(x). 대문자 F(x)는 부정적분/원시함수 표기.
- 도함수: f'(x), f''(x). 라이프니츠 표기 d/dx 도 사용.
- 합성함수: (f∘g)(x) 또는 f(g(x)). 시험지에서는 후자 우세.
- 역함수: f^{-1}(x) 또는 별도 문자 g(x)로 정의.
- 극한: lim_{x→a} f(x), lim_{n→∞} a_n.
- 좌·우극한: lim_{x→a-} f(x), lim_{x→a+} f(x).
- 극값/극대/극소: "극값", "극댓값", "극솟값".

### 7.2 적분

- 정적분: ∫_a^b f(x)dx
- 부정적분: ∫f(x)dx
- 정적분으로 정의된 함수: F(x) = ∫_a^x f(t)dt 형태. 변수 구분 위해 적분 안에서는 t 사용.
- 넓이: "곡선 y=f(x)와 x축으로 둘러싸인 부분의 넓이"
- 부피(미적분): "회전체의 부피 = ∫π[f(x)]^2 dx"

### 7.3 수열

- 일반항: a_n. 첨자는 _n으로.
- 합: Σ_{k=1}^{n} a_k 또는 "수열 {a_n}의 첫째항부터 제 n 항까지의 합 S_n"
- 점화식: a_{n+1} = ..., 또는 "a_n과 a_{n+1} 사이에 ~이 성립한다"
- 등비수열의 공비: r (또는 q)
- 등차수열의 공차: d

### 7.4 삼각함수

- sin x, cos x, tan x (괄호 없이 인수 작성). 단 인수가 식일 때는 sin(2x+π/3).
- 라디안 기본. 도(°) 거의 사용 안 함.
- 주기: 2π, π. π/2, π/3, π/6 등 특수각.

### 7.5 지수·로그

- 지수: a^x, e^x. (e는 자연로그의 밑)
- 로그: log_a x (밑 명시), ln x (자연로그).
- 상용로그: log x (밑 10 생략).

### 7.6 절댓값과 부등식

- |x|, |f(x)|. 절댓값 안에 식 통째.
- 부등식: a ≤ x < b 형태로 양변 한정. 반열림/닫힌 구간 명확히.
- 집합 표기: { x | 조건 } 보다 "~인 모든 x" 형태의 한국어 진술 우세.

## 8. 그림·도형 문제 도입어

- "그림과 같이 ~"
- "좌표평면 위에 두 점 A(1, 2), B(3, 4)가 있다."
- "원 x^2 + y^2 = 4 위의 점 P에서 ..."
- "삼각형 ABC에서 ∠A = π/3, AB = 4, AC = 5일 때 ..."
- 도형 정점은 A, B, C, D, P, Q, R 순.

## 9. 변수·문자 사용 관행

- 함수: f, g, h
- 점: P, Q, R, A, B, C, D
- 각: ∠A, ∠ABC, θ, α, β
- 정수 변수: n, m, k
- 실수 변수: a, b, c, t, x, y, k
- 상수: c (constant)
- 자연수 카운트: n
- 두 자연수가 등장하면 m, n 또는 p, q

## 10. 보기·답 표기

- 객관식 5지선다는 ①②③④⑤ 원형 숫자. 수식 본문에서는 1, 2, 3, 4, 5로도 표기.
- 단답형 답: 자연수 0~999.
- "단, p와 q는 서로소인 자연수이다." → 분수 답을 묻고 p+q를 답으로 하는 트릭. 답 범위가 정수로 제한되기 때문.
- "단, k는 양의 정수이다." 같은 한정.

## 11. 출제 트렌드별 발문 변화

- **킬러 배제 정책(2024~)**: 발문이 더 짧고 조건 수가 줄어드는 경향. 2024수능 22번은 조건이 (가) 1개로 간결.
- **그러나 조건이 짧을수록 해석 부담 증가** — 조건 1개에 여러 케이스가 함축되어 케이스 분기 필요.
- 2026학년도부터 합답형 부활. ㄱㄴㄷ 양식 재등장.

## 12. 금지·기피되는 표현

수능 문제에 거의 등장하지 않는 표현(이를 사용하면 수능답지 않음):

- 행렬 (2009 개정에서 제외)
- 복소수 (수능 출제범위 외)
- 벡터 (확통·미적분에 없음. 기하 선택자만)
- "증명하시오" (수능은 객관식+단답형이므로 증명 발문 없음)
- "다음 중 옳지 않은 것은?" → 합답형은 "옳은 것"만. "옳지 않은 것" 양식은 다른 영역에서 더 흔함.
- "왜?", "이유는?" 같은 서술형
